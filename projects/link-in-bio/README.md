# Link in Bio

![Link in Bio screenshot](./screenshot.png)

Build a Linktree-style bio page: profile (name, handle, bio, avatar, accent
theme) and a list of **reorderable link buttons**, with an Edit / Preview toggle.

A single self-contained HTML page (Tailwind via CDN). Category: **creative**
(influencers, creators).

## Load it into App Studio

- **Load it straight in** — use [`link-in-bio.appstudio`](./link-in-bio.appstudio):
  **Share → Import**, or drop it into your `App Studio Projects` folder.
- **Copy-paste** — open [`link-in-bio.html`](./link-in-bio.html), copy it all,
  then **New → paste → Run App**.

## Notes

- In preview, the link buttons open their URLs in a new tab. **No runtime service
  dependency**; everything is saved in `localStorage`.
- Keep the header comment and the source link at the top of the file. See the
  root [LICENSE](../../LICENSE) for the terms.
