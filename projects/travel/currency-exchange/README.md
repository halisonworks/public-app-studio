# Currency Exchange & the Spread

> ⚠️ **Example, not a product.** This project was generated as a starting point and learning aid. It may contain mistakes, simplified models, or inaccurate numbers — do not rely on any calculation or result for real decisions without checking it yourself.

![Currency Exchange & the Spread screenshot](./screenshot.png)

A teaching tool for the **Sales, Service and Tourism** classroom that answers a
question every traveller asks: *why do I get less money back than I changed?*
It makes the **spread** (the gap between the buy and sell rates) and fees
visible, with a round-trip demo that shows the hidden cost. Rates are editable
mock data — there is no live feed.

A single self-contained HTML page (Tailwind via CDN), with **Learn**,
**Practice**, and a full-screen **Present** mode. Category: **Travel** (teaching · reiseliv). **English UI.**

## Load it into App Studio

- **Load it straight in** — use [`currency-exchange.appstudio`](./currency-exchange.appstudio):
  **Share → Import**, or drop it into your `App Studio Projects` folder.
- **Copy-paste** — open [`currency-exchange.html`](./currency-exchange.html),
  copy it all, then **New → paste → Run App**.

## Notes

- **Rates are mock, editable data — not a live feed.** This is deliberate: the
  tool teaches how the spread works and has **no runtime service dependency**.
