# Complaint & Conflict Handling

> ⚠️ **Example, not a product.** This project was generated as a starting point and learning aid. It may contain mistakes, simplified models, or inaccurate numbers — do not rely on any calculation or result for real decisions without checking it yourself.

![Complaint & Conflict Handling screenshot](./screenshot.png)

A service-recovery trainer for the **Sales, Service and Tourism** classroom.
Learn a de-escalation model (Listen · Acknowledge · Solve · Thank), then practise
on branching customer-complaint scenarios — overbooking, a cancelled excursion,
an angry billing dispute — where each choice moves the customer's mood and leads
to a different outcome. All branches are scripted; there is no AI.

A single self-contained HTML page (Tailwind via CDN), with **Learn**,
**Practice**, and a full-screen **Present** mode. Category: **Travel** (teaching · reiseliv). **English UI.**

## Load it into App Studio

- **Load it straight in** — use [`complaint-handling.appstudio`](./complaint-handling.appstudio):
  **Share → Import**, or drop it into your `App Studio Projects` folder.
- **Copy-paste** — open [`complaint-handling.html`](./complaint-handling.html),
  copy it all, then **New → paste → Run App**.

## Notes

- The scenarios are hand-authored decision trees. **No runtime service
  dependency** — nothing is generated by an AI at runtime.
