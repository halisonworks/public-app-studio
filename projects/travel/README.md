# Travel projects

Travel / tourism tools — for a personal traveller planning a trip, and for the
**Sales, Service and Tourism** (*salg, service og reiseliv*) classroom.

## Personal travel

- [Trip Budget](./trip-budget/) — plan a trip's cost per person and per day, by category
- [Trip Split](./trip-split/) — split shared costs and see the simplest "who owes whom"
- [Time Zones & Flight](./timezones-flight/) — world clock plus an arrival-time / layover calculator
- [Itinerary](./itinerary/) — a day-by-day plan for the whole trip

## Teaching (reiseliv / service)

Learn / Practice / Present tools for the things that are hard to grasp from a
definition alone:

- [Currency Exchange & the Spread](./currency-exchange/) — why you get less back than you changed
- [Complaint & Conflict Handling](./complaint-handling/) — a branching service-recovery trainer
- [Risk Assessment](./risk-assessment/) — a likelihood × consequence (HMS) matrix builder
