# Color Palette Generator

![Color Palette Generator screenshot](./screenshot.png)

Generate harmonious 5-color palettes. **Lock** the colors you like, reroll the
rest with **Generate**, and **click a swatch to copy** its hex.

A single self-contained HTML page (Tailwind via CDN). Category: **creative /
generative** — colors are derived in HSL for intentional, harmonious results.

## Load it into App Studio

- **Load it straight in** — use [`color-palette.appstudio`](./color-palette.appstudio):
  **Share → Import**, or drop it into your `App Studio Projects` folder.
- **Copy-paste** — open [`color-palette.html`](./color-palette.html), copy it
  all, then **New → paste → Run App**.

## Notes

- **No runtime service dependency** — all generation is local. Copying hex codes
  uses the browser clipboard.
- No image-export button — use App Studio's built-in **PNG export** to save a
  palette as an image.
- Made with the [creative](../../prompts/context/creative.md) category add-on.
- Keep the header comment and the source link at the top of the file. See the
