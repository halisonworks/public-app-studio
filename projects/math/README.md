# Math (Norwegian curriculum)

Interactive maths learning tools for Norwegian upper-secondary students, written
in **Norwegian (Bokmål)** and organized by curriculum level (LK20). Each tool
pairs a short explanation with interactive figures, calculators, and worked
results.

> ⚠️ **Examples, not products.** These tools can contain errors or simplified
> models — verify any calculation before relying on it.

- [`NO-2P/`](./NO-2P/) — matematikk 2P (praktisk matematikk)
- [`NO-1P/`](./NO-1P/) — matematikk 1P (praktisk matematikk)
