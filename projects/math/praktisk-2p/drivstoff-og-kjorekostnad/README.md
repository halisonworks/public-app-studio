# Drivstoff og kjørekostnad

![Drivstoff og kjørekostnad screenshot](./screenshot.png)

> ⚠️ **Example, not a product.** This project was generated as a starting point and learning aid. It may contain mistakes, simplified models, or inaccurate numbers — do not rely on any calculation or result for real decisions without checking it yourself.

Fuel used and what a trip costs, and compare alternatives.

Practical everyday maths for Norwegian **matematikk 2P** (LK20) — for work and
home. **Norwegian UI.** A single self-contained HTML page (Tailwind via CDN).
Category: **Math · 2P praktisk**.

## Load it into App Studio

- **Load it straight in** — use [`drivstoff-og-kjorekostnad.appstudio`](./drivstoff-og-kjorekostnad.appstudio):
  **Share → Import**, or drop it into your `App Studio Projects` folder.
- **Copy-paste** — open [`drivstoff-og-kjorekostnad.html`](./drivstoff-og-kjorekostnad.html), copy it all, then
  **New → paste → Run App**.

## Notes

- **No runtime service dependency** — all maths is computed locally.
