# Praktisk matematikk 2P

Hverdagsmatte for **jobb og privat** — praktiske 2P-verktøy (LK20) som viser
hvordan matematikken brukes i virkeligheten.

> ⚠️ Eksempler, ikke ferdige produkter — sjekk tall og priser før du stoler på dem.

- [Enhetspris](./enhetspris/) — pris per kg/liter/stk og beste kjøp
- [Strømkostnad](./stromkostnad/) — kWh og strømregning
- [Materialberegning](./materialberegning/) — maling, fliser/gulv og betong
- [Drivstoff og kjørekostnad](./drivstoff-og-kjorekostnad/) — forbruk og turkostnad
- [Lønn med tillegg](./lonn-med-tillegg/) — overtid og kvelds-/helgetillegg
- [Rabatt og tilbud](./rabatt-og-tilbud/) — rabatt, mengdetilbud og flere rabatter
