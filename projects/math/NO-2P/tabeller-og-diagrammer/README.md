# Tabeller og diagrammer

![Tabeller og diagrammer screenshot](./screenshot.png)

> ⚠️ **Example, not a product.** This project was generated as a starting point and learning aid. It may contain mistakes, simplified models, or inaccurate numbers — do not rely on any calculation or result for real decisions without checking it yourself.

Build a **frekvenstabell** (with relative and cumulative frequency) from your
data, then view the same data as a **søylediagram**, **kurvediagram**, and
**sektordiagram**. Covers Sinus 2P kapittel 2.

Interactive learning tool for Norwegian **matematikk 2P** (LK20). **Norwegian UI.**
A single self-contained HTML page (Tailwind via CDN; hand-rolled SVG charts).
Category: **Math · NO-2P**.

## Load it into App Studio

- **Load it straight in** — use [`tabeller-og-diagrammer.appstudio`](./tabeller-og-diagrammer.appstudio):
  **Share → Import**, or drop it into your `App Studio Projects` folder.
- **Copy-paste** — open [`tabeller-og-diagrammer.html`](./tabeller-og-diagrammer.html),
  copy it all, then **New → paste → Run App**.
