# Matematikk 2P (NO-2P)

Interaktive læremidler for **matematikk 2P** (LK20), på norsk. Hvert verktøy har
en kort forklaring, interaktive figurer/kalkulatorer og utregninger.

> ⚠️ Eksempler, ikke ferdige produkter — de kan inneholde feil. Sjekk
> utregninger før du stoler på dem.

- [Prosent og prosentpoeng](./prosent-og-prosentpoeng/) — prosentpoeng vs. prosentvis endring + prosentkalkulator
- [Vekstfaktor](./vekstfaktor/) — gjentatt prosentvis endring, tabell og graf
- [Lineære funksjoner](./lineaere-funksjoner/) — y = ax + b interaktivt
- [Statistikk](./statistikk/) — sentralmål og spredning med histogram
- [Geometri (2P)](./geometri/) — areal, Pytagoras, volum/overflate, målestokk

See the full catalog with screenshots: [../../../catalog.md](../../../catalog.md).
