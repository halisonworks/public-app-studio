# Funksjoner og vekst

![Funksjoner og vekst screenshot](./screenshot.png)

> ⚠️ **Example, not a product.** This project was generated as a starting point and learning aid. It may contain mistakes, simplified models, or inaccurate numbers — do not rely on any calculation or result for real decisions without checking it yourself.

Plot **linear, quadratic, power, and exponential** functions with sliders, see
their **kjennetegn**, and explore **gjennomsnittlig** (secant) and **momentan**
(tangent) **vekstfart**. Covers Sinus 2P kapittel 5.

Interactive learning tool for Norwegian **matematikk 2P** (LK20). **Norwegian UI.**
A single self-contained HTML page (Tailwind via CDN; hand-rolled SVG graph).
Category: **Math · NO-2P**.

## Load it into App Studio

- **Load it straight in** — use [`funksjoner-og-vekst.appstudio`](./funksjoner-og-vekst.appstudio):
  **Share → Import**, or drop it into your `App Studio Projects` folder.
- **Copy-paste** — open [`funksjoner-og-vekst.html`](./funksjoner-og-vekst.html),
  copy it all, then **New → paste → Run App**.
