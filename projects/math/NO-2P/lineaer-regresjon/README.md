# Lineær regresjon

![Lineær regresjon screenshot](./screenshot.png)

> ⚠️ **Example, not a product.** This project was generated as a starting point and learning aid. It may contain mistakes, simplified models, or inaccurate numbers — do not rely on any calculation or result for real decisions without checking it yourself.

Enter (x, y) data points, fit the **least-squares line** y = ax + b, plot the
points and the line, and use the model to **predict** — with a note on
extrapolation. Covers Sinus 2P kapittel 4 (lineære modeller og regresjon).

Interactive learning tool for Norwegian **matematikk 2P** (LK20). **Norwegian UI.**
A single self-contained HTML page (Tailwind via CDN; hand-rolled SVG). Category:
**Math · NO-2P**.

## Load it into App Studio

- **Load it straight in** — use [`lineaer-regresjon.appstudio`](./lineaer-regresjon.appstudio):
  **Share → Import**, or drop it into your `App Studio Projects` folder.
- **Copy-paste** — open [`lineaer-regresjon.html`](./lineaer-regresjon.html),
  copy it all, then **New → paste → Run App**.
