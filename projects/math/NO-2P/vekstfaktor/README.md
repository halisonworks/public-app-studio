# Vekstfaktor

![Vekstfaktor screenshot](./screenshot.png)

> ⚠️ **Example, not a product.** This project was generated as a starting point and learning aid. It may contain mistakes, simplified models, or inaccurate numbers — do not rely on any calculation or result for real decisions without checking it yourself.

Teaches the **growth factor** (vekstfaktor) and repeated percentage change:
percentage change → growth factor → value after *n* periods, with a per-period
table and chart — plus a reverse mode to find the growth factor from start, end,
and *n*.

Interactive learning tool for Norwegian **matematikk 2P** (LK20). **Norwegian UI.**
A single self-contained HTML page (Tailwind via CDN). Category: **Math · NO-2P**.

## Load it into App Studio

- **Load it straight in** — use [`vekstfaktor.appstudio`](./vekstfaktor.appstudio):
  **Share → Import**, or drop it into your `App Studio Projects` folder.
- **Copy-paste** — open [`vekstfaktor.html`](./vekstfaktor.html), copy it all,
  then **New → paste → Run App**.
