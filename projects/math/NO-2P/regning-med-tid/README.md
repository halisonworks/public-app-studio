# Regning med tid

![Regning med tid screenshot](./screenshot.png)

> ⚠️ **Example, not a product.** This project was generated as a starting point and learning aid. It may contain mistakes, simplified models, or inaccurate numbers — do not rely on any calculation or result for real decisions without checking it yourself.

Time arithmetic and unit conversion, plus speed = distance / time.

Interactive learning tool for Norwegian **matematikk** (LK20). **Norwegian UI.**
A single self-contained HTML page (Tailwind via CDN). Category: **Math · NO-2P**.

## Load it into App Studio

- **Load it straight in** — use [`regning-med-tid.appstudio`](./regning-med-tid.appstudio):
  **Share → Import**, or drop it into your `App Studio Projects` folder.
- **Copy-paste** — open [`regning-med-tid.html`](./regning-med-tid.html), copy it all, then
  **New → paste → Run App**.

## Notes

- **No runtime service dependency** — all maths is computed locally.
