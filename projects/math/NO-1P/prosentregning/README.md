# Prosentregning

![Prosentregning screenshot](./screenshot.png)

> ⚠️ **Example, not a product.** This project was generated as a starting point and learning aid. It may contain mistakes, simplified models, or inaccurate numbers — do not rely on any calculation or result for real decisions without checking it yourself.

Percentage factor, increase/decrease, finding the original value, and VAT (MVA). Covers Sinus 1P Kap. 2.1–2.5.

Interactive learning tool for Norwegian **matematikk 1P** (LK20). **Norwegian UI.**
A single self-contained HTML page (Tailwind via CDN). Category: **Math · NO-1P**.

## Load it into App Studio

- **Load it straight in** — use [`prosentregning.appstudio`](./prosentregning.appstudio):
  **Share → Import**, or drop it into your `App Studio Projects` folder.
- **Copy-paste** — open [`prosentregning.html`](./prosentregning.html), copy it all, then
  **New → paste → Run App**.

## Notes

- **No runtime service dependency** — all maths is computed locally.
