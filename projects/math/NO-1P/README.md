# Matematikk 1P (NO-1P)

Interaktive læremidler for **matematikk 1P** (LK20), på norsk. Hvert verktøy har
en kort forklaring, interaktive figurer/kalkulatorer og utregninger.

> ⚠️ Eksempler, ikke ferdige produkter — de kan inneholde feil. Sjekk
> utregninger før du stoler på dem.

- [Forhold og proporsjonalitet](./forhold-og-proporsjonalitet/) — forhold, proporsjonalitet, skalering
- [Enheter og måling](./enheter-og-maaling/) — omgjøring av enheter og målestokk
- [Lønn og skatt](./lonn-og-skatt/) — brutto → netto med trekkprosent og feriepenger
- [Sannsynlighet](./sannsynlighet/) — gunstige/mulige, teoretisk vs. eksperimentell
- [Geometri (1P)](./geometri/) — areal, Pytagoras, volum og overflate
