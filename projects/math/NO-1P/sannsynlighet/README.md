# Sannsynlighet

![Sannsynlighet screenshot](./screenshot.png)

> ⚠️ **Example, not a product.** This project was generated as a starting point and learning aid. It may contain mistakes, simplified models, or inaccurate numbers — do not rely on any calculation or result for real decisions without checking it yourself.

Probability as **gunstige / mulige utfall**: pick an experiment (die, coin, or an
adjustable wheel), see the theoretical probabilities, then **simulate** many
trials and watch the experimental frequencies approach them.

Interactive learning tool for Norwegian **matematikk 1P** (LK20). **Norwegian UI.**
A single self-contained HTML page (Tailwind via CDN; hand-rolled SVG bars).
Category: **Math · NO-1P**.

## Load it into App Studio

- **Load it straight in** — use [`sannsynlighet.appstudio`](./sannsynlighet.appstudio):
  **Share → Import**, or drop it into your `App Studio Projects` folder.
- **Copy-paste** — open [`sannsynlighet.html`](./sannsynlighet.html), copy it
  all, then **New → paste → Run App**.

## Notes

- **No runtime service dependency** — outcomes are simulated locally.
