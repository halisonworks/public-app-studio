# Enheter og måling

![Enheter og måling screenshot](./screenshot.png)

> ⚠️ **Example, not a product.** This project was generated as a starting point and learning aid. It may contain mistakes, simplified models, or inaccurate numbers — do not rely on any calculation or result for real decisions without checking it yourself.

Convert between units of **length, mass, volume, and time**, see the value in
every unit of a category at once, and work with **map scale** (målestokk) both
ways. Explains the metric prefixes.

Interactive learning tool for Norwegian **matematikk 1P** (LK20). **Norwegian UI.**
A single self-contained HTML page (Tailwind via CDN). Category: **Math · NO-1P**.

## Load it into App Studio

- **Load it straight in** — use [`enheter-og-maaling.appstudio`](./enheter-og-maaling.appstudio):
  **Share → Import**, or drop it into your `App Studio Projects` folder.
- **Copy-paste** — open [`enheter-og-maaling.html`](./enheter-og-maaling.html),
  copy it all, then **New → paste → Run App**.

## Notes

- **No runtime service dependency** — all conversion is computed locally.
