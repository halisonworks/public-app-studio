# Vinkler

![Vinkler screenshot](./screenshot.png)

> ⚠️ **Example, not a product.** This project was generated as a starting point and learning aid. It may contain mistakes, simplified models, or inaccurate numbers — do not rely on any calculation or result for real decisions without checking it yourself.

Angle types, the angle sum in triangles and polygons, and angle pairs (vertical / supplementary).

Interactive geometry tool for Norwegian **matematikk 1P/2P** (LK20). **Norwegian UI.**
A single self-contained HTML page (Tailwind via CDN; hand-rolled SVG). Category:
**Math · Geometri**.

## Load it into App Studio

- **Load it straight in** — use [`vinkler.appstudio`](./vinkler.appstudio):
  **Share → Import**, or drop it into your `App Studio Projects` folder.
- **Copy-paste** — open [`vinkler.html`](./vinkler.html), copy it all, then
  **New → paste → Run App**.

## Notes

- **No runtime service dependency** — all maths is computed locally.
- Keep the header comment and the source link at the top of the file. See the
