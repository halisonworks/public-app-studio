# Eksamenstrening 2P

![Eksamenstrening 2P screenshot](./screenshot.png)

> ⚠️ **Example, not a product.** This project was generated as a starting point and learning aid. It may contain mistakes, simplified models, or inaccurate numbers — do not rely on any calculation or result for real decisions without checking it yourself.

Practice and exam trainer: random tasks with hints and full solutions, in Del 1 / Del 2 format.

Interactive learning tool for Norwegian **matematikk** (LK20). **Norwegian UI.**
A single self-contained HTML page (Tailwind via CDN). Category: **Math · 2P**.

## Load it into App Studio

- **Load it straight in** — use [`eksamenstrening-2p.appstudio`](./eksamenstrening-2p.appstudio):
  **Share → Import**, or drop it into your `App Studio Projects` folder.
- **Copy-paste** — open [`eksamenstrening-2p.html`](./eksamenstrening-2p.html), copy it all, then
  **New → paste → Run App**.

## Notes

- **No runtime service dependency** — all maths is computed locally.
- Keep the header comment and the source link at the top of the file. See the
