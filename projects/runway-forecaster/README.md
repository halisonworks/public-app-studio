# Runway Forecaster

![Runway Forecaster screenshot](./screenshot.png)

Project your startup's cash over 24 months: **runway**, zero-cash date, net
burn, and an optional fundraise — with a live cash-balance chart and KPI cards.

A single self-contained HTML page (Tailwind via CDN). Category: **business /
finance** (founders, finance).

## Load it into App Studio

- **Load it straight in** — use [`runway-forecaster.appstudio`](./runway-forecaster.appstudio):
  **Share → Import**, or drop it into your `App Studio Projects` folder.
- **Copy-paste** — open [`runway-forecaster.html`](./runway-forecaster.html),
  copy it all, then **New → paste → Run App**.

## Notes

- Recalculates live as you change the inputs; **no runtime service dependency**,
  saved in `localStorage`.
- Keep the header comment and the source link at the top of the file. See the
  root [LICENSE](../../LICENSE) for the terms.
