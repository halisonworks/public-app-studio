# Pricing Page

> ⚠️ **Example, not a product.** This project was generated as a starting point and learning aid. It may contain mistakes, simplified models, or inaccurate numbers — do not rely on any calculation or result for real decisions without checking it yourself.

![Pricing Page screenshot](./screenshot.png)

A polished SaaS pricing page: three tiers with a **monthly / annual** billing
toggle, a highlighted "most popular" plan, and a feature-comparison table.

A single self-contained HTML page (Tailwind via CDN). Category: **business /
sales & marketing**.

## Load it into App Studio

- **Load it straight in** — use [`pricing-page.appstudio`](./pricing-page.appstudio):
  **Share → Import**, or drop it into your `App Studio Projects` folder.
- **Copy-paste** — open [`pricing-page.html`](./pricing-page.html), copy it all,
  then **New → paste → Run App**.

## Notes

- A self-contained marketing page — **no backend, payments, or login**; the CTA
  buttons confirm a selection rather than charging.
- Edit the tiers, prices, and features inline near the top of the script to make
  it your own.
- Made with the [business](../../../prompts/context/business.md) category add-on.
- Keep the header comment and the source link at the top of the file. See the
  root [LICENSE](../../../LICENSE) for the terms.
