# Patronymikon

> ⚠️ **Eksempel, ikke et produkt.** Laget som utgangspunkt og læringshjelp. Det kan inneholde feil eller forenklinger — kontroller mot kildene før du stoler på et resultat.

Bygg og tolk norske **patronymer**. Skriv inn farens fornavn og få barnets
patronym i både moderne (Ole → **Olsen / Olsdatter**) og eldre/dialektal form
(**Olsson / Olsdotter**) — eller gå motsatt vei: skriv inn «Olsdatter» og se at
faren het Ole/Ola og at personen var en kvinne. Et eget kort forklarer
gårdsnavn-som-etternavn og navneloven av 1923.

En selvstendig HTML-side (Tailwind via CDN). Kategori: **slektsforskning (norsk)**.

## Last inn i App Studio

- **Last rett inn** — bruk [`patronymikon.appstudio`](./patronymikon.appstudio):
  **Share → Import**, eller slipp den i mappa `App Studio Projects`.
- **Kopier–lim** — åpne [`patronymikon.html`](./patronymikon.html), kopier alt, og
  **New → paste → Run App**.

## Merknader

- Patronymet er farsnavnet + `-sen/-son` (sønn) eller `-datter/-dotter` (datter).
  Skrivemåten varierte (Hansen/Hanssen, Rasmusen/Rasmussen), og stamme → fornavn er
  ikke alltid entydig — verktøyet viser alternativer der det er flere.
- Kjører helt uten nett; inndata lagres i `localStorage`. Behold header-kommentaren
  og kildelenken. Se [LICENSE](../../../../LICENSE) for vilkår.
