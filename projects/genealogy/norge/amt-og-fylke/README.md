# Amt ↔ fylke

> ⚠️ **Eksempel, ikke et produkt.** Laget som utgangspunkt og læringshjelp. Kontroller stedsnavn mot kilden din.

Gamle kilder bruker **amtsnavn** som «Smaalenenes amt» eller «Nordre Bergenhus
amt». Slå dem opp mot dagens fylke, og se hele tidslinjen for området: amt (før
1919) → fylke (1919–2019) → region (2020) → status fra 2024. Søk live, klikk en
rad for detaljer, eller slå opp motsatt vei fra et moderne fylke. Et hierarki-kort
forklarer rike → amt/fylke → fogderi/prestegjeld → sokn.

En selvstendig HTML-side (Tailwind via CDN). Kategori: **slektsforskning (norsk)**.

## Last inn i App Studio

- **Last rett inn** — bruk [`amt-og-fylke.appstudio`](./amt-og-fylke.appstudio):
  **Share → Import**, eller slipp den i mappa `App Studio Projects`.
- **Kopier–lim** — åpne [`amt-og-fylke.html`](./amt-og-fylke.html), kopier alt, og
  **New → paste → Run App**.

## Merknader

- Amtene ble til fylker 1. januar 1919; Kristiania ble Oslo i 1925.
  Sammenslåingene i 2020 (Viken, Vestland, Innlandet, Troms og Finnmark m.fl.) ble
  delvis reversert fra 2024. Kirkebøker er ordnet etter prestegjeld og sokn — søk
  i Digitalarkivet for disse.
- Kjører helt uten nett; inndata lagres i `localStorage`. Behold header-kommentaren
  og kildelenken. Se [LICENSE](../../../../LICENSE) for vilkår.
