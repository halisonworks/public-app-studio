# Ressurser & datasett

> ⚠️ **Eksempel, ikke et produkt.** Laget som utgangspunkt og læringshjelp. Lenker kan endre adresse — sjekk nettstedene selv.

Et organisert, **søkbart lenkebibliotek** til de viktigste kildene for norsk
slektsforskning: Digitalarkivet, Arkivverket, Nasjonalbiblioteket, RHD og Histreg,
Slekt og Data, Lokalhistoriewiki, gravminnebaser, utvandringskilder, DNA-verktøy
og de store internasjonale basene. Filtrer i sanntid, og stjernemerk favorittene
dine (lagres lokalt). Tenk på det som en startside for arkivøkta.

En selvstendig HTML-side (Tailwind via CDN). Kategori: **slektsforskning (norsk)**.

## Last inn i App Studio

- **Last rett inn** — bruk [`ressurser-og-datasett.appstudio`](./ressurser-og-datasett.appstudio):
  **Share → Import**, eller slipp den i mappa `App Studio Projects`.
- **Kopier–lim** — åpne [`ressurser-og-datasett.html`](./ressurser-og-datasett.html),
  kopier alt, og **New → paste → Run App**.

## Merknader

- Lenkene er vanlige `<a href>`-lenker (ingen kjøring av kode); noen baser er
  gratis, andre krever abonnement (merket i lista).
- Kjører helt uten nett (selve sida); favoritter lagres i `localStorage`. Behold
  header-kommentaren og kildelenken. Se [LICENSE](../../../../LICENSE) for vilkår.
