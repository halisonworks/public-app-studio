# Norsk slektsforskning

Verktøy laget spesielt for **norsk** slektsforskning, skrevet på **bokmål**. Norsk
slektsgransking har sine helt egne utfordringer — patronymer og gårdsnavn,
menning-systemet (søskenbarn, tremenning …), kirkebøker datert etter kirkeåret,
kalenderreformen i 1700, gamle amtsnavn og gamle mål og mynt. Disse verktøyene
tar for seg nettopp det, og peker mot de norske kildene (Digitalarkivet,
Arkivverket, RHD, Slekt og Data m.fl.).

> ⚠️ **Eksempler, ikke produkter.** Verktøyene er laget som utgangspunkt og
> læringshjelp. De kan inneholde feil eller forenklinger — kontroller alltid mot
> originalkildene før du stoler på et resultat.

- [Ane-aldersestimator](./ane-aldersestimator/) — sannsynlige fødselsår for
  foreldre og forfedre, for å avgrense søk i Digitalarkivet
- [Patronymikon](./patronymikon/) — bygg og tolk patronymer (Ole → Olsen/Olsdatter),
  med gårdsnavn og navneloven av 1923
- [Slektskap (norske termer)](./slektskap-norsk/) — søskenbarn, tremenning,
  firmenning, grandonkel … og slektskapsgrad
- [Ressurser & datasett](./ressurser-og-datasett/) — søkbart lenkebibliotek til de
  viktigste norske kildene
- [Bayesiansk farskaps-sannsynlighet](./biologisk-far-bayes/) — pedagogisk
  Bayes-demo: feilfar-rate + DNA-bevis → oppdatert sannsynlighet
- [Gamle mål & mynt](./gamle-maal-og-mynt/) — alen, favn, tønne, skålpund,
  speciedaler, ort, skilling → metrisk og 1875-kroner
- [Kirkeårskalender](./kirkekalender/) — påskeregning, bevegelige helligdager, og
  «N. søndag etter trinitatis»-datoer med riktig kalender før/etter 1700
- [Amt ↔ fylke](./amt-og-fylke/) — gamle amtsnavn mot dagens fylker (1919, 2020, 2024)

Alle verktøyene er selvstendige HTML-sider (Tailwind via CDN), kjører helt uten
nett, og lagrer inndata i `localStorage`.

Se hele katalogen med skjermbilder: [../../../catalog.md](../../../catalog.md).
