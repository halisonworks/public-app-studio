# Slektskap (norske termer)

> ⚠️ **Eksempel, ikke et produkt.** Laget som utgangspunkt og læringshjelp. Det kan inneholde feil eller forenklinger — kontroller mot kildene før du stoler på et resultat.

Finn det riktige norske slektskapsordet for to slektninger. Fortell hvor mange
ledd hver person er fra den **felles anen**, så gir verktøyet ordet —
**søskenbarn**, **tremenning**, **firmenning**, **grandonkel**, og de motsatte
termene — med slektskapsgrad og et lite nedstigningsdiagram. Velg kjønn på de to
for å få kjønnede ord (fetter/kusine, onkel/tante, nevø/niese).

En selvstendig HTML-side (Tailwind via CDN). Kategori: **slektsforskning (norsk)**.

## Last inn i App Studio

- **Last rett inn** — bruk [`slektskap-norsk.appstudio`](./slektskap-norsk.appstudio):
  **Share → Import**, eller slipp den i mappa `App Studio Projects`.
- **Kopier–lim** — åpne [`slektskap-norsk.html`](./slektskap-norsk.html), kopier
  alt, og **New → paste → Run App**.

## Merknader

- Menning-systemet teller ledd til felles ane: søsken (1), søskenbarn (2),
  tremenning (3), firmenning (4), femmenning (5) … Ulikt antall ledd gir
  «forskjøvet»-former.
- Kjører helt uten nett; inndata lagres i `localStorage`. Behold header-kommentaren
  og kildelenken. Se [LICENSE](../../../../LICENSE) for vilkår.
