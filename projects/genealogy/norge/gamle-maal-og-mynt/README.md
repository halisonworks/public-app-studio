# Gamle mål & mynt

> ⚠️ **Eksempel, ikke et produkt.** Laget som utgangspunkt og læringshjelp. Mange gamle mål varierte regionalt og over tid — kontroller mot kilden din.

Konverter gamle norske enheter du møter i skifter, panteregister og gamle
dokumenter: **lengde** (alen, fot, favn, mil), **areal** (mål, kvadratalen),
**hulmål** (tønne, skjeppe, pot, kanne), **vekt** (skålpund, lispund, bismerpund,
skippund) og **mynt** (speciedaler, ort, skilling → 1875-kroner). Velg kategori,
skriv inn en mengde, og se alle ekvivalentene med én gang.

En selvstendig HTML-side (Tailwind via CDN). Kategori: **slektsforskning (norsk)**.

## Last inn i App Studio

- **Last rett inn** — bruk [`gamle-maal-og-mynt.appstudio`](./gamle-maal-og-mynt.appstudio):
  **Share → Import**, eller slipp den i mappa `App Studio Projects`.
- **Kopier–lim** — åpne [`gamle-maal-og-mynt.html`](./gamle-maal-og-mynt.html),
  kopier alt, og **New → paste → Run App**.

## Merknader

- Verdiene er de standardiserte (metrisk tid). Mynt-omregningen viser **pålydende
  1875-kroner** (1 spd = 4 kr), ikke dagens kjøpekraft. Matrikkelskyld
  (skylddaler) er en skatteverdi, ikke et areal.
- Kjører helt uten nett; inndata lagres i `localStorage`. Behold header-kommentaren
  og kildelenken. Se [LICENSE](../../../../LICENSE) for vilkår.
