    About / How Soundex works

    Soundex is a phonetic index that groups surnames that sound alike but are spelled differently. The U.S. National Archives (NARA) used it to index the 1880, 1900, 1910 and 1920 federal censuses, and the same coding underpins many immigration, naturalization and passenger-list indexes. To find an ancestor in those microfilmed indexes you look up the surname's Soundex code rather than its spelling.

    This tool implements the standard American Soundex (the NARA rules), not the Daitch–Mokotoff Soundex used for Eastern European and Jewish surnames.

    Coding rules

    1. Keep the first letter of the surname.
    2. Assign digits to the remaining letters:
    1B F P V
    2C G J K Q S X Z
    3D T
    4L
    5M N
    6R
    1. The vowels A E I O U and Y are not coded, but they do separate two consonants — so the same digit on either side of a vowel is coded twice.
    2. H and W are skipped without separating: two equal digits on either side of an H or W are still coded only once.
    3. Collapse adjacent letters with the same digit (including a first letter sharing the next letter's digit) into a single digit.
    4. Append zeros, then truncate so the code is exactly one letter + three digits, e.g. W252.
